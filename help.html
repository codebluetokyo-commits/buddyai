HOW TO USE

覚えることは、三つだけ。

Buddy AI にはたくさんの機能がありますが、入口はどれも同じ場所にあります。タップ、長押し、スワイプ。この三つを知っていれば、あとは話しかけるだけです。

BASICS

三つの基本操作

画面の中央にいるキャラクターが、すべての入口です。触り方によって、開くものが変わります。

話しかける

TAP（タップ）— 一回さわる

キャラクターを軽くタップすると、まわりに八つのメニューが円を描いて開きます。声で話すのも、文字で打つのも、ここから。

声を録る

HOLD（ホールド）— 一秒ほど押さえたまま

そのまま押し続けると録音が始まります。会議でも、歩きながらの思いつきでも。止めたあとに、メモ・議事録・テキスト・Word から選べます。

画面を移る

SWIPE（スワイプ）— 下のふちを横になぞる

画面のいちばん下を横になぞると、下部メニューが出ます。右から左でも、左から右でも構いません。保存したものを見返すのはここから。三秒で自然に消えます。

INDEX

やりたいことから探す

機能の名前ではなく、その時したいことから引けるようにしました。

会議の記録を残したい
キャラクターを長押しすると録音が始まります。音声の案内が流れ、画面に ● REC と出れば録音中。参加者の名前を先に伝えておくと、誰の発言かを聞き分けます。終わったらもう一度タップして停止。 長押し → 話す → タップで停止 → 「議事録としてまとめる」
思いついたことを声で残したい
同じく長押しから。止めたあとに「録音メモとして保存」を選べば、文字起こしがそのまま残ります。要約はいらない、生の言葉のままがいい、というときに。 長押し → タップで停止 → 「録音メモとして保存」
保存したものを見返したい
画面のいちばん下を横になぞると、下部メニューが現れます。右から左でも、左から右でも構いません。「保存済み」に議事録・レポート・録音メモ・出力ファイルがまとまっています。三秒で消えるので、出たら続けて押してください。 下のふちを横になぞる → 保存済み
聞き流した話を、あとで読み直したい
移動中は耳で聞くだけで十分でも、机に戻ってから確かめたくなることがあります。メニューの📋ご報告に、これまでの返答が残っています。声で受け取ったものを、目で追い直すための場所です。ホーム画面の返答の下に出る「ご報告で全文を読む」からも、そのまま開けます。 タップ → 📋ご報告　／　返答の下の「全文を読む」
予定やリマインダーを入れたい
話しかけるだけで登録されます。「明日14時に歯医者」「来週の月曜に請求書を出すこと」。日時が曖昧でも文脈から補います。専用の画面が要るときは、メニューの📅予定から。 タップ → 🎤話す →「明日14時に歯医者の予約を登録して」
調べ物をしたい
そのまま聞いてください。最新の情報が要る質問だと判断すれば、自分で調べに行きます。移動中に聞くことを想定して、答えは短くまとめます。じっくり読みたいときは🔍調べるから。詳しい報告が返ります。 タップ → 🎤話す、または 🔍調べる
相手に言葉を伝えたい
メニューの🌐翻訳から。訳した文は A+ で大きくでき、全画面にも広げられます。画面を相手に向けて、そのまま読んでもらうための作りです。声で入れることも、看板やメニューを撮って訳すこともできます。 タップ → 🌐翻訳 → 訳す → A+ で大きく → 相手に向ける
写真について聞きたい
メニューの📷画像から写真を渡せます。書いてある文字を読む、内容を説明する、二枚を見比べる。届いたメッセージの画面を見せて「これ、怪しい？」と聞けば、詐欺の疑いも見ます。 タップ → 📷画像
相談に乗ってほしい
仕事の段取りとは違う話も、ここでできます。決めかねていること、誰にも言っていないこと、うまく言葉にならないこと。話す相手は、いま選んでいる十人のうちの一人です。同じことを聞いても、執事と猫では返ってくる言葉が違います。 タップ → 🤝相談
相手を変えたい・名前を変えたい
右下の歯車から設定を開き、「キャラクターを選ぶ」で十人から。それぞれ口調も声も違います。✏️から名前も変えられるので、好きな呼び名をつけてください。 ⚙️設定 → キャラクターを選ぶ
MEMORY

覚えることから、
先を読むことへ。

Buddy AI が、ただ命令を待つ道具ではないと感じてもらえるとしたら、それはここの働きによるものです。

設定の「私のことを覚えてほしい」に、仕事や立場、いま抱えていることを書いておけます。ここに書かれたことは、次の応答から前提になります。毎回説明しなくてよくなる、というのがまず一つ。

それとは別に、会話のなかから自然に覚えていく仕組みも働いています。何度も話題に出ること、繰り返し頼まれること。そうしたものが少しずつ蓄えられ、あなたの文脈として残ります。使うほど、前置きが要らなくなります。

ただ、わたしたちが本当に目指しているのは、その先です。

覚えているだけでは、まだ受け身のままです。頼まれてから動くのではなく、頼まれる前に気づく。この時間なら次はあれだろう、この件ならあの資料が要るだろう、と。人が優れた執事や秘書に感じる頼もしさは、記憶の量ではなく、その先読みの精度から来ています。

そこに届くまでには、まだ時間がかかります。次のバージョンで正面から取り組む予定です。いま覚えていることは、そのための土台でもあります。

1987年に Apple が描いた Knowledge Navigator は、画面の向こうの相手が、こちらの文脈を分かっている世界でした。あの映像から四十年近く経ちますが、まだ誰も完全には作っていません。作っている途中です。

MENU

メニュー八つの使い分け

タップで開く八つは、性格が二種類に分かれています。前の二つは「どうやって伝えるか」。残りの六つは「専用の画面への近道」です。迷ったら🎤話すで構いません。たいていのことは、言葉で伝われば動きます。

🎤話す声で伝える。いちばんの近道
⌨️テキスト静かな場所や、正確に打ちたいとき
📷画像写真を見せて聞く
📋ご報告頼んだ仕事の報告を読み返す
🌐翻訳訳した文を大きく出して、相手に見せる
🔍調べる詳しく調べてほしいとき
📅予定日時を自分で指定して入れる
🤝相談迷っていること、決めかねていること

「話す」と「調べる」の違い

どちらでも調べ物はできます。違うのは、返ってくる長さです。🎤話すは移動中に耳で聞くことを想定して、要点を短くまとめます。🔍調べるは腰を据えて読むための画面なので、詳しい報告が返ります。同じことを聞いても、返り方が変わります。

TROUBLE

困ったときは

つまずきやすいところを集めました。

下のメニューが消えてしまった
三秒で自動的に隠れる作りです。もう一度、画面のいちばん下を横になぞってください。出ている間に押せば、そのまま移動できます。
録音が始まったか分からない
始まると音声で案内が流れ、画面の表示が「● REC」に変わります。押す時間が短いとメニューが開くだけなので、一秒ほど押さえたままにしてください。
前に話したことを覚えていない
設定の「私のことを覚えてほしい」に、仕事や状況を書いておけます。会話の中から自然に覚えることもありますが、大事なことは先に伝えておくほうが確実です。
子どもに触られたくない
設定の「画面ロック」を入れると、いたずら操作を防げます。カバンの中での誤動作にも。
それでも解決しないとき
サポートページからご連絡ください。返信までお時間をいただくことがありますが、必ず目を通しています。

まずは、話しかけてみてください。
